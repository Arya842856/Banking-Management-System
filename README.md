# 🏦 Bank Management System

A Java-based Bank Management System developed using **Java, JDBC, and MySQL**. This project demonstrates database connectivity and basic banking data management using a structured Java application.

## 📌 Project Overview

The Bank Management System is designed to demonstrate how a Java application can interact with a MySQL database using **JDBC (Java Database Connectivity)**.

The project includes classes for managing customers, accounts, and database connectivity.

## ✨ Features

* 👤 Customer management
* 🏦 Bank account management
* 🔗 MySQL database connectivity
* 💾 JDBC integration
* 📊 Database-driven application
* 🧩 Organized Java package structure
* 🔌 Reusable database connection utility

## 🛠️ Technologies Used
